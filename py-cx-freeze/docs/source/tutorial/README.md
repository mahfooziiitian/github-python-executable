# Introduction

`cx_Freeze` is a Python library used to convert Python scripts into executable files (EXE) for Windows, macOS, and Linux. It's especially useful when you want to distribute Python applications to users who may not have Python installed.

cx_Freeze creates standalone executables from Python scripts with the same performance as the original script. It is cross-platform and should work on any platform that Python runs on.

The current version of cx_Freeze is 8.4 that supports Python  3.9 to 3.13, providing on pypi, wheels for Linux (x86_64, aarch64, ppc64le), macOS (universal2) and Windows (win32, win_amd64, win_arm64).

## Key Features of cx_Freeze

1. Converts .py files into standalone executables.
2. Supports Python 3.x.
3. Handles dependencies automatically.
4. Works with GUI frameworks like Tkinter, PyQt, wxPython, etc.
